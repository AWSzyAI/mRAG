# E15：Gemma4 E4B-it 终答生成器对比实验

生成时间：2026-04-23

## 1. 实验目的

E15 用于验证更大的 Gemma4 E4B-it 是否能超过 E8 中的 LLaVA-OneVision 7B 终答器，并补充 E9 中 Gemma4 E2B-it 终答能力不足的问题。

实验保持 E8/E9 的检索侧主架构不变：

- Gemma4 生成 5 条多维检索 query；
- MagicLens 对每一维进行 full corpus Top-5 检索；
- RRF 融合得到最终 Top-5 视觉证据；
- Gemma4 对 query image 与最终证据图生成辅助描述；
- Gemma4 对 query image + Top-5 evidence images 进行多选题终答。

核心变量：

| 实验 | Gemma4 模型 | 检索规划 | 检索器 | 融合 | 证据描述 | 终答生成器 |
|---|---|---|---|---|---|---|
| E8 | E2B-it | Gemma4 E2B-it | MagicLens | RRF | Gemma4 E2B-it | LLaVA-OneVision |
| E9 | E2B-it | Gemma4 E2B-it | MagicLens | RRF | Gemma4 E2B-it | Gemma4 E2B-it |
| E15 | E4B-it | Gemma4 E4B-it | MagicLens | RRF | Gemma4 E4B-it | Gemma4 E4B-it |

## 2. 新增代码

- `test/gemma4-e4b-it.py`
  - E4B 专用下载与冒烟测试脚本；
  - 默认模型：`google/gemma-4-E4B-it`；
  - 默认本地目录：`models/gemma4-e4b-it`；
  - 下载逻辑可在轻量节点运行；推理冒烟测试懒加载 `test/gemma4.py` 的加载、文本生成、图文生成与显存统计逻辑。

- `test/E15_gemma4_e4b_answerer.sh`
  - E15 专用服务器启动脚本；
  - 默认输出到 `log/E15/`；
  - 默认使用 `--describe-final-images`，便于与 E9 做同设置对比。

## 3. 服务器下载与预检

在仓库根目录运行：

```bash
python test/gemma4-e4b-it.py --mode download
```

下载后做单机冒烟测试：

```bash
python test/gemma4-e4b-it.py --mode run --device cuda:0
```

如果服务器模型路径不同：

```bash
python test/gemma4-e4b-it.py \
  --mode download \
  --model-id google/gemma-4-E4B-it \
  --local-dir /public/home/hzh/mRAG/models/gemma4-e4b-it
```

若模型需要门禁访问，先确认已经接受 Hugging Face 协议，并设置：

```bash
export HF_TOKEN=...
```

## 4. E15 运行命令

先跑小样本检查：

```bash
MAX_SAMPLES=20 bash test/E15_gemma4_e4b_answerer.sh
```

全量运行：

```bash
bash test/E15_gemma4_e4b_answerer.sh
```

如果服务器路径不同：

```bash
CORPUS_DIR=/public/home/hzh/mRAG/data/image_corpus \
GEMMA4_LOCAL_DIR=models/gemma4-e4b-it \
GEMMA4_MODEL_ID=google/gemma-4-E4B-it \
GEMMA4_DEVICE=cuda:0 \
bash test/E15_gemma4_e4b_answerer.sh
```

后台运行后查看：

```bash
cat log/E15/E15_gemma4_e4b_answer.pid
tail -f log/E15/E15_gemma4_e4b_answer.log
```

## 5. 输出文件

| 文件 | 内容 |
|---|---|
| `log/E15/E15_gemma4_e4b_answer.log` | 运行日志 |
| `log/E15/E15_gemma4_e4b_answer.pid` | 后台进程 PID |
| `log/E15/e15_gemma4_e4b_answer.jsonl` | 每题最终答案、预测选项、正确性与 fused evidence |
| `log/E15/e15_gemma4_e4b_answer_summary.json` | overall accuracy、分场景 accuracy、平均耗时 |
| `log/E15/e15_gemma4_e4b_answer_dims.jsonl` | 每题 5 条检索维度与 rationale |
| `log/E15/e15_gemma4_e4b_answer_trace.jsonl` | 完整 trace：维度生成、5x5 检索、RRF 融合、图像描述、Gemma4 E4B 终答 |

## 6. 跑完后的检查命令

```bash
python3 - <<'PY'
import json
from pathlib import Path
p = Path("log/E15/e15_gemma4_e4b_answer_summary.json")
d = json.loads(p.read_text())
print(json.dumps(d, indent=2, ensure_ascii=False))
PY

rg -n '"meta_pred_choice": "N/A"|gemma4_answer_error|dimension_gen_error|image_description_error' log/E15
```

期望：

- `processed=1353`；
- `dim_gen_failures=0` 或接近 0；
- `meta_pred_choice=N/A` 数量尽量为 0；
- `accuracy` 直接与 E8 的 56.32% 和 E9 的 Gemma4 E2B-it 结果对比；
- `avg_dim_gen_time_sec`、`avg_final_answer_time_sec` 用于评估 E4B 的额外耗时是否值得。
