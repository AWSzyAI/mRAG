# W9：Recall@5 / Recall@N 统计说明（基于数据集 GT 字段）

更新时间：2026-04-22

本文档记录三件事：

1. Recall@5 和 Recall@N 的统一计算口径
2. 统计时涉及到的代码与数据文件
3. MRAG-Bench 数据集字段格式（尤其是 GT 字段）

## 1. 计算口径（统一定义）

对每个样本，先取数据集里的 GT 证据集合，然后与实验输出的检索结果做匹配。

- Recall@5：最终送入终答器的 Top-5 证据中，命中 GT 的覆盖比例（按样本平均）
- Recall@N：融合前候选池中，命中 GT 的覆盖比例（按样本平均）

单样本定义：

- 设 GT 唯一集合为 G，|G| = m
- 设最终 Top-5 唯一集合为 F5
- 设候选池唯一集合为 FN（N 为候选池大小）

则：

- recall_at_5 = |G ∩ F5| / max(1, m)
- recall_at_n = |G ∩ FN| / max(1, m)

补充统计（用于多维查询分析）：

- gt_hits_at_n：候选池内命中 GT 的次数（保留重复命中）
- candidate_count：候选池总长度 N

说明：

- 对单列表实验（如 E3/E6/E7），候选池就是一条检索列表，通常 N=5，所以 Recall@5 与 Recall@N 数值相同
- 对多维实验（如 E8/E9/E10/E11/E12/E13），N 通常为 N_dim × K_dim；融合或去重后 N 可能小于该理论值

## 3. MRAG-Bench 数据集格式（已核验）

使用 test split 读取样本后，字段如下：

- id
- question
- answer
- answer_choice
- scenario
- aspect
- A, B, C, D（多选项文本）
- image（query 图）
- gt_images（GT 证据图列表）
- retrieved_images（官方检索图列表）
- image_type
- source

已在本地环境核验 test[:1] 的类型信息：

- gt_images 是长度通常为 5 的图像列表（Incomplete 场景按协议可只取 1）
- retrieved_images 是长度通常为 5 的图像列表
- 图像对象类型示例为 JpegImageFile，包含 mode/size/info
- 图像对象不稳定携带文件名，不能依赖 filename 直接做匹配

因此，当前统一口径采用图像内容哈希匹配（脚本内为 dHash）来完成 GT 与检索结果对齐。

## 4. 计算流程（按当前脚本）

1. 从 MRAG-Bench 读取每个样本的 gt_images，转换为 GT 哈希集合
2. 对于 E2，直接用 retrieved_images 作为候选池
3. 对于 E3/E6/E7 等 results 日志，从 meta_corpus_retrieval 读取路径，再映射到语料图像哈希
4. 对于 E8+ 的 trace 日志：
	 - final_paths 来自 fusion.selected
	 - candidate_paths 来自 magiclens_retrieval.calls[*].top_k
5. 对每个样本计算 recall_at_5 与 recall_at_n
6. 对全数据集做均值，生成总表可填数字

## 5. 在论文总表中新增 N 列的写法建议

表 4.1 中 Recall@N 旁新增一列 N，建议填写为：

- E0/E1/E5：N=5（人工标注证据）
- E2：N=5（官方 retrieved_images）
- E3/E6/E7：N=5（单路 Top-5）
- E8：N=25（默认 N_dim=5, K_dim=5；若有去重可再注明 unique N 平均值）

如果后续跑了 E11/E12，可按各自参数替换 N。

## 6. 复现实验命令（环境可用时）

建议在 llava 环境执行：

python scripts/analyze_recall_e0_e13.py \
	--dataset-name uclanlp/MRAG-Bench \
	--split test \
	--corpus-dir data/image_corpus \
	--csv-out log/E13/e0_e13_recall_metrics.csv \
	--json-out log/E13/e0_e13_recall_metrics.json \
	--plot-out paper/images/e0_e13_recall.png

说明：脚本依赖 datasets 与本地语料目录 data/image_corpus；若本机无语料目录，需要在服务器端执行后回传统计结果。
