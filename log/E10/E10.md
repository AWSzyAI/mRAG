# E10：查询重写消融实验（No Query Rewrite）

生成时间：2026-04-22

## 1. 实验目的

E10 用于补充论文中“查询重写模块消融”的结果。E8 的核心设计是先由 Gemma4 E2B-it 根据 query image、question 和 choices 生成 5 条互补检索维度，再分别调用 MagicLens 检索并用 RRF 融合。E10 则去掉这一查询侧扩展：

- 不生成 5 个维度；
- 不进行 query rewriting；
- 直接把原始 `question + choices` 作为单条 MagicLens 检索 instruction；
- MagicLens 从 full corpus 中取 Top-5；
- 后续证据描述与最终 LLaVA 终答保持和 E8 一致。

因此 E8 与 E10 的主要对照变量是：

| 实验 | 检索 query | 检索次数 | 检索器 | 最终候选 | 证据描述 | 终答生成器 |
|---|---|---:|---|---|---|---|
| E8 | Gemma4 5 维 query rewrite | 5 | MagicLens | RRF Top-5 | Gemma4 | LLaVA-OneVision |
| E10 | 原始 question + choices | 1 | MagicLens | Top-5 | Gemma4 | LLaVA-OneVision |

E10 的目标不是替代 E8，而是回答：E8 的提升究竟来自 MagicLens 本身，还是来自 Gemma4 多维查询重写与多路融合。

## 6. 论文填表建议

论文中 `tab:ablation_rewrite_placeholder` 可以填为：

| 设置 | 检索 query | 检索次数 | Overall Acc. | 平均检索耗时 | 备注 |
|---|---|---:|---:|---:|---|
| 无查询重写（E10） | 原始 question + choices | 1 | 53.51 | 0.709s | 直接 MagicLens Top-5 |
| 多维查询重写（E8） | Gemma4 生成 5 维 query | 5 | 56.32 | 3.40s | 本文主架构 |

分析时建议重点看两类指标：

1. Overall accuracy：衡量 query rewriting 是否真正提升端到端答题。
2. 分场景 accuracy：尤其关注 `Incomplete`、`Temporal`、`Biological` 和 `Others`。如果 E8 在这些场景明显优于 E10，说明多维 query 更容易覆盖结构补全、状态变化和细粒度语义证据。

## 7. 与 E8 的关键区别

E8 的每个样本会产生 25 个候选输入融合层（5 维 x 每维 Top-5），RRF 再选最终 Top-5；E10 只有 1 路 Top-5，因此 RRF 在 E10 中退化为单列表排序。这样设计的好处是变量非常干净：E10 去掉的是“多维查询重写 + 多路召回”，其余评测链路尽量保持一致。

## 9. 与 E8 的结果对比与解释

### 9.1 总体结论

- E10（53.51）相比 E8（56.32）低 **2.81** 个百分点；
- 这说明 E8 的提升并不只来自 MagicLens 检索器本身，**多维 query rewrite + 多路召回融合**确实贡献了有效增益。

### 9.2 分场景差异（E10 - E8）

| 场景 | E10 | E8 | 差值 |
|---|---:|---:|---:|
| Scope | 61.76 | 59.80 | +1.96 |
| Obstruction | 56.48 | 57.41 | -0.93 |
| Temporal | 57.72 | 54.36 | +3.36 |
| Deformation | 53.92 | 54.90 | -0.98 |
| Biological | 57.84 | 56.86 | +0.98 |
| Angle | 54.66 | 57.45 | -2.79 |
| Partial | 50.81 | 54.07 | -3.26 |
| Incomplete | 24.51 | 29.41 | -4.90 |
| Others | 61.67 | 80.00 | -18.33 |

主要观察：

1. E10 在 `Temporal`、`Scope` 上略优，说明这两类题里原始 question+choices 已能提供较强检索信号。
2. E10 在 `Others` 上显著落后（-18.33），是总体差距的主要来源；这类题往往需要多角度语义扩展，多维 query 的优势最明显。
3. `Incomplete` 与 `Partial` 在 E10 中也更弱，表明单路 query 对结构不完整或局部证据题的覆盖能力不足。

### 9.3 逐样本胜负（E8 vs E10）

按相同 `qs_id` 对齐 1353 题：

- E8 独对 126 题；
- E10 独对 88 题；
- E8 净领先 **+38** 题。

其中 E8 净收益主要来自：

- `Others`：+22（26 vs 4）
- `Angle`：+9（26 vs 17）
- `Partial`：+8（19 vs 11）
- `Incomplete`：+5（15 vs 10）

这与上面的分场景趋势一致：query rewrite 的核心价值在于补偿单路 query 容易遗漏的多粒度视觉语义线索。

## 10. 可写入论文的结论（建议文案）

在保持 MagicLens、证据描述与 LLaVA 终答链路不变时，去除查询重写后（E10）overall accuracy 从 56.32% 降至 53.51%（-2.81）。结果说明 E8 的收益不仅来自检索器替换，更来自 Gemma4 多维查询重写与 RRF 多路融合。尤其在 `Others`、`Partial`、`Incomplete` 等需要多角度证据覆盖的场景，多维 query 的贡献更为关键。
