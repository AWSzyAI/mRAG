# E9：Gemma4 E2B 终答生成器对比实验

生成时间：2026-04-22

## 1. 实验目的

E9 用于补充论文中“LLaVA 与 Gemma 4 终答生成器对比”的空表。实验保持 E8 的检索侧主架构不变：

- Gemma4 E2B-it 生成 5 条多维检索 query；
- MagicLens 对每一维进行 full corpus Top-5 检索；
- RRF 融合得到最终 Top-5 视觉证据；
- Gemma4 对 query image 与最终证据图生成辅助描述；
- 仅将最后的多选题终答器从 E8 的 LLaVA-OneVision 替换为 Gemma4 E2B-it。

因此 E8 与 E9 的主要对照变量是：

| 实验 | 检索规划 | 检索器 | 融合 | 证据描述 | 终答生成器 |
|---|---|---|---|---|---|
| E8 | Gemma4 E2B-it | MagicLens | RRF | Gemma4 E2B-it | LLaVA-OneVision |
| E9 | Gemma4 E2B-it | MagicLens | RRF | Gemma4 E2B-it | Gemma4 E2B-it |

### 6.1 完整性与运行状态

E9 全量处理 `processed=1353`，`correct=527`，overall accuracy 为 **38.95%**。维度生成失败数为 `dim_gen_failures=0`，最终答题阶段 `meta_final_answer_error=0`，每个样本均输入 6 张图，即 query image + RRF Top-5 evidence。`meta_pred_choice=N/A` 共 4 题，其中 2 题为空输出，1 题输出 `E`，1 题输出“choices are not provided”式拒答；这类抽取失败只占 0.30%，不是 E9 准确率下降的主因。

### 6.2 与 E8_full 的同口径对比

E8_full 与 E9 保持相同检索侧设置，差别只在最终答题器：E8_full 使用 LLaVA-OneVision，E9 使用 Gemma4 E2B-it。因此二者可以作为“同一批 RRF 证据由不同 VLM 读证据并答题”的直接对照。

| 实验 | 终答生成器 | Correct / Processed | Overall Acc. | Avg final answer | Avg sample total |
|---|---|---:|---:|---:|---:|
| E8_full | LLaVA-OneVision | 762 / 1353 | 56.32 | 0.338s | 42.580s |
| E9 | Gemma4 E2B-it | 527 / 1353 | 38.95 | 1.455s | 33.941s |
| E9 - E8 | Gemma4 - LLaVA | -235 | -17.37 | +1.117s | -8.639s |

准确率上，E9 相比 E8_full 下降 **17.37** 个百分点，净少 235 题。逐样本交叉统计为：

| 类型 | 题数 |
|---|---:|
| E8 与 E9 都答对 | 376 |
| E8 对、E9 错 | 386 |
| E8 错、E9 对 | 151 |
| E8 与 E9 都答错 | 440 |

这说明 Gemma4 终答器并不是简单“整体更保守”或“只在无效输出上损失”；它确实在 151 个 E8 错题上给出了正确答案，但在 386 个 E8 正确样本上丢分更多，净效应为 -235。

### 6.3 分场景结果

| Scenario | 样本数 | E8_full Acc. | E9 Acc. | 差值 |
|---|---:|---:|---:|---:|
| Scope | 102 | 59.80 | 30.39 | -29.41 |
| Obstruction | 108 | 57.41 | 37.04 | -20.37 |
| Temporal | 149 | 54.36 | 41.61 | -12.75 |
| Deformation | 102 | 54.90 | 29.41 | -25.49 |
| Biological | 102 | 56.86 | 25.49 | -31.37 |
| Angle | 322 | 57.45 | 44.72 | -12.73 |
| Partial | 246 | 54.07 | 36.99 | -17.08 |
| Incomplete | 102 | 29.41 | 26.47 | -2.94 |
| Others | 120 | 80.00 | 63.33 | -16.67 |

E9 最好的场景是 `Others`，达到 63.33%，但仍比 E8_full 低 16.67 个百分点。`Angle` 和 `Temporal` 是相对可接受的两类，分别为 44.72% 和 41.61%，与 E8 的差距约 12.7 个百分点。`Incomplete` 原本就是 E8 的短板，E9 只低 2.94 个百分点，说明这类题的主要瓶颈更可能在检索证据本身，而不是终答器。

E9 下降最严重的是 `Biological`、`Scope` 和 `Deformation`：分别比 E8_full 低 31.37、29.41 和 25.49 个百分点。这三类通常需要细粒度物种/类别辨别、原图目标边界判断、局部形变后的视觉结构判断。Gemma4 E2B-it 作为终答器读同一组证据时，可能更容易被检索图中的相似类别、辅助描述或选项文本干扰，未能像 LLaVA 那样稳定利用 query image 与 evidence 的互补关系。

### 6.4 答案分布与无效输出

E9 的预测选项分布为：

| Pred | Count |
|---|---:|
| A | 274 |
| B | 421 |
| C | 315 |
| D | 339 |
| N/A | 4 |

GT 分布为 A=353、B=285、C=365、D=350。E9 对 B 的预测明显偏多，对 A 的预测偏少。这种偏置不是唯一问题，但会放大细粒度分类题的损失，尤其在候选选项语义相近时，模型可能被证据描述中的泛化类别词带偏。

从 raw output 看，大多数输出仍是单字母：`B` 416 次、`D` 335 次、`C` 314 次、`A` 261 次。少量长文本虽然能被 `extract_choice(...)` 抽取出选项，但也暴露出 Gemma4 终答器偶尔没有严格遵循“只输出字母”的指令。例如有输出会复述 choices，有输出会解释“无法确定”，还有一题输出了 `E`。不过这些格式问题总量很小，不足以解释 17.37 个百分点的整体差距。

### 6.5 耗时分析

| 阶段 | E8_full mean | E9 mean | E9 median | E9 p95 |
|---|---:|---:|---:|---:|
| 维度生成 | 17.586s | 12.911s | 12.891s | 14.295s |
| MagicLens 检索 + RRF | 3.399s | 3.324s | 3.250s | 4.250s |
| Gemma4 图像描述 | 21.007s | 16.249s | 15.888s | 22.057s |
| 最终答题 | 0.338s | 1.455s | 1.411s | 1.654s |
| 单样本总耗时 | 42.580s | 33.941s | 33.621s | 40.350s |

E9 的终答阶段比 E8 的 LLaVA 慢约 1.12s，但 E9 的维度生成和图像描述阶段更快，所以本次记录到的总耗时反而更低。这个总耗时差异不应过度解释为模型架构优劣，因为两次全量运行的服务器状态、缓存和模型加载细节可能不同；但可以确定的是，E9 的主要失败不是性能或异常问题，而是终答质量问题。

### 6.6 当前结论

E9 的结论比较明确：在当前 prompt 和证据组织方式下，把 E8 的最终答题器从 LLaVA-OneVision 换成 Gemma4 E2B-it 会显著降低准确率，overall 从 56.32% 降到 **38.95%**。由于检索规划、MagicLens 检索、RRF 融合和 Gemma4 图像描述均保持一致，下降主要应归因于 Gemma4 E2B-it 对“query image + Top-5 evidence + 辅助描述 + 多选项”的最终判别能力不足，或当前终答 prompt/多图输入格式不适配该模型。

论文中可以把 E9 作为生成器对比的负向结果：同样的检索证据并不保证不同 VLM 终答器都能有效利用；LLaVA-OneVision 在多图证据整合和选择题输出稳定性上明显优于 Gemma4 E2B-it。后续若要继续优化 Gemma4 终答路线，优先尝试：

- 将终答 prompt 改成更强约束的 JSON/letter-only 格式，并减少辅助描述中的干扰文本。
- 分离 query image 与 retrieved evidence 的角色，明确“以 query image 为主、证据图只作参考”。
- 做 ablation：Gemma4 仅 query image、Gemma4 query image + evidence images、不加 Gemma4 descriptions、只给 evidence descriptions 不给 evidence images。
- 对细粒度类别题减少背景证据权重，避免 Scope/Biological/Deformation 中被相似但错误的 retrieved images 带偏。
