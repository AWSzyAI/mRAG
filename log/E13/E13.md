## 1. 实验目的

E13 用于补齐 E8 管线中的融合策略消融。E8 默认使用 RRF，本实验保持 E8 其他设置不变，仅替换多维检索结果的融合算子：

- E13_1：Score Sum，按跨维相似度分数求和；
- E13_2：Voting，按候选在多维列表中的出现频次投票；
- E8 / E13_0：RRF，作为默认对照。

固定设置：

| 项目 | 设置 |
|---|---|
| 数据集 | `uclanlp/MRAG-Bench` test split |
| 维度生成器 | Gemma4 E2B-it |
| 查询维度数 | `n_dims=5` |
| 每维候选数 | `dim_top_k=5` |
| 最终候选数 | `final_top_k=5` |
| 检索器 | MagicLens |
| 证据描述 | Gemma4 |
| 终答生成器 | LLaVA-OneVision |

唯一变量：

| 实验 | 融合方式 | 脚本 | Summary |
|---|---|---|---|
| E8 / E13_0 | RRF | 已完成 | `log/E8_full/e8_full_summary.json` |
| E13_1 | Score Sum | `test/E13_1.sh` | `log/E13/E13_1_score_sum/e13_1_score_sum_summary.json` |
| E13_2 | Voting | `test/E13_2.sh` | `log/E13/E13_2_voting/e13_2_voting_summary.json` |

## 3. 跑完后的汇总命令

```bash
python3 - <<'PY'

        d.get("avg_dim_gen_time_sec"), d.get("avg_retrieval_time_sec"),
        d.get("avg_final_answer_time_sec", ""), d.get("dim_gen_failures"),
    ])))
```
