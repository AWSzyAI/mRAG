## 当前方法主线

当前论文中必须持续强化以下方法主线：

1. 以 CLIP 作为稳健粗召回器
2. 以 MagicLens 作为关系感知重排模块
3. 引入查询重写，把 `Question` 映射为更适合检索的 `query`
4. 使用 pipeline LLM 组织查询链与中间推理，其中 CoT 用于分解检索需求（推理期）
5. 通过多维指令扩展查询侧表达，并以融合算子压缩多路排序结果
6. 在统一脚本入口下完成对比实验与结果资产沉淀，保证结论可追溯
