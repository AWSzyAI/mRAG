## 一、答辩核心叙事

本论文的核心问题不是“怎样让 VQA 模型更强”，而是：

**在完整外部图像库中，系统如何根据问题条件找到真正有助于回答的视觉证据。**

整场答辩围绕三句话展开：

1. 视觉相似图像不一定是有效证据，vision-centric mRAG 的关键瓶颈在检索阶段。
2. 本文用 CLIP 提供稳定视觉邻域，用 MagicLens 补充关系感知能力，并通过 Gemma 4 多维查询规划与 RRF 融合组织证据。
3. 实验表明，Optimized Multi Query RAG(E11_4) 达到 57.43%，优于 CLIP/MagicLens 单路完整语料库检索基线，并比初始 Multi Query RAG(E8) 更高效。

**演讲稿**

这是本文的主方法 Multi Query RAG(E8)。整体流程分为三个阶段。第一，Gemma 4 根据查询图像、题干和选项生成多条互补的检索指令，也就是把一个复杂问题拆成多个证据搜索维度。第二，MagicLens 对每条指令分别进行关系感知检索，得到多路候选列表。第三，系统使用 RRF 对多路结果进行融合，压缩为固定数量的 Top-5 证据图像，再交给 LLaVA-OneVision 进行最终多选题回答。这个方法不更新模型参数，而是在推理流程中改进查询构造和证据组织。

## 五、10 分钟完整串讲稿

各位老师好，我的论文题目是《基于混合检索器的多模态生成模型研究与实现》。本文研究的是以视觉为中心的多模态检索增强生成任务。和普通视觉问答不同，这类任务不仅给定查询图像和问题，还提供一个外部图像库。系统需要先从图像库中检索能够支撑回答的视觉证据，再把查询图像、问题和证据图像一起交给视觉语言模型完成最终回答。

本文关注的核心问题是：系统究竟应该检索什么样的视觉证据。传统检索很容易被理解为寻找视觉上相似的图像，但在 MRAG-Bench 这类任务中，视觉相似不一定等于证据有效。比如问题可能关注局部结构、时间状态、遮挡关系或者范围判断，这些条件未必能通过通用视觉相似度直接捕捉。因此，本文认为 vision-centric mRAG 的关键瓶颈不只是终答模型能力，而是检索阶段能否把真正有用的问题相关证据带到模型面前。

基于这个判断，本文设计了一个混合检索式框架。CLIP 负责提供稳定的视觉邻域召回，MagicLens 负责补充开放式指令下的关系感知检索能力，Gemma 4 负责把原始问题拆分成多个面向证据召回的检索维度，最后使用 RRF 对多路检索结果进行融合。融合后的 Top-5 证据图像和查询图像、问题文本一起输入 LLaVA-OneVision，由它输出最终多选题答案。

具体来说，本文主方法 Multi Query RAG(E8) 首先由 Gemma 4 读取查询图像、题干和选项，生成多条短英文检索指令。每条指令对应一个不同的检索视角，例如主体识别、局部细节、背景关系或相似候选。随后，MagicLens 按每条指令分别在完整图像语料库中检索候选图像。最后，系统通过 RRF 融合多路候选，得到固定长度的最终证据集合，再交给 LLaVA-OneVision 终答。这个方法的特点是推理期扩展，不需要更新模型参数，而是从查询构造和证据组织上改进系统。

在样例中可以看到，同一个问题会被拆成多个互补检索方向。不同维度返回的候选既可能存在重复命中，也可能提供互补证据。RRF 的作用不是简单扩大候选数量，而是在多个维度之间形成候选共识，同时保留一定多样性。这样，最终进入终答模型的不是某一路检索的原始输出，而是经过多维查询和列表融合组织后的证据集合。

实验方面，本文在 MRAG-Bench test split 的 1353 个样本上进行评估。完整图像库检索基线表现说明任务确实困难：CLIP Retrieval(E3) 的整体准确率为 50.41%，CLIP Rerank(E6) 为 50.33%，MagicLens Retrieval(E7) 为 47.97%。本文初始 Multi Query RAG(E8) 达到 56.32%，明显高于上述完整语料库检索基线。进一步参数优化后，四维查询配置 Optimized Multi Query RAG(E11_4) 达到 57.43%。相较最强完整全库检索基线提升 7.02 个百分点，相较 MagicLens 直接检索提升 9.46 个百分点。虽然与人工证据参考设置 60.16% 仍有差距，但已经显著改善了非人工证据条件下的全库检索表现。

为了进一步解释方法为什么有效，本文分析了证据召回率和参数设置。Multi Query RAG(E8) 的最终 Recall@5 为 5.42%，但融合前候选池 Recall@N 达到 14.13%。这说明多维查询真正扩大的主要是融合前的有效证据覆盖范围，而最终 Top-5 的压缩仍然会带来信息损失。参数实验也说明，多维查询并不是维度越多越好。五维 E8 的整体准确率为 56.32%，平均耗时 42.58 秒；四维 E11_4 的整体准确率提高到 57.43%，平均耗时降到 29.97 秒。这表明减少一个噪声维度后，系统在证据覆盖、噪声控制和运行效率之间取得了更好的折中。

此外，CLIP 与 MagicLens 的候选集合分析也支持本文的混合检索思路。两者并不是在同一批候选上做微小排序调整，而是具有不同的检索偏好。CLIP 更稳定地保持视觉邻域，MagicLens 在部分结构性、关系性场景中更有优势，但也存在单路偏置和候选集中问题。因此，本文不是简单替换检索器，而是通过查询侧规划、多路召回和融合，把不同检索能力重新组织起来。

总结来说，本文的主要贡献有三点。第一，从问题导向视觉证据检索的角度重新分析 vision-centric mRAG，强调有效证据不同于视觉相似图。第二，设计了结合 CLIP、MagicLens、Gemma 4 和 RRF 的混合检索式框架。第三，通过主实验、召回分析、参数实验和候选结构分析验证了该框架在完整图像库检索条件下的有效性。未来可以继续提升最终证据选择机制，降低证据描述生成成本，并探索更细粒度的检索器优化方式。
