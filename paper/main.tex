\begin{center}
{\zihao{3}\bfseries 摘\quad 要\par}
\end{center}
\addcontentsline{toc}{chapter}{摘\texorpdfstring{\quad}{ }要}
\noindent\hspace*{\parindent}%
在以视觉为中心的多模态检索增强生成（vision-centric mRAG）任务中，系统需要根据查询图像和问题文本，从外部图像库中寻找能够补足回答所需信息的视觉证据。与文本检索增强主要补充事实性文本不同，该任务面对的是查询图像、自然语言问题和候选证据图像之间的三方关系：查询图像给出待解释对象或场景，问题文本限定需要补足的视觉条件，外部图像库则提供可能的辅助证据。因此，检索目标不再只是寻找视觉外观相似的图像，而是寻找能够支撑当前问题理解与回答判断的证据图像。

本文基于 MRAG-Bench 展开研究，该数据集将多模态问答组织为“查询图像 + 问题文本 + 外部候选图像库”的任务形式，要求系统先检索与问题相关的视觉证据，再利用查询图像和证据图像完成多选题回答。围绕这一任务，本文设计了一个由三部分组成的多模态检索增强架构：第一部分是查询侧规划，用于根据查询图像、题干和选项生成面向证据召回的检索表达；第二部分是视觉证据检索与融合，用于在完整图像库中按不同检索维度召回候选图像，并将多路结果合并为固定长度的证据集合；第三部分是多模态终答生成，用于把查询图像、检索证据和问题文本共同输入视觉语言模型，输出最终选项。该架构面向 MRAG-Bench 中问题条件视觉证据召回的需求，能够将原始问答任务拆分为查询构造、证据组织和终答生成三个可分析环节。

实验结果表明，完整图像库检索仍是 vision-centric mRAG 的主要瓶颈。CLIP 直接全库检索基线的整体准确率为 50.41\%，CLIP 召回后结合 MagicLens 重排为 50.33\%，MagicLens 直接全库检索为 47.97\%。本文初始多维融合检索框架在 MRAG-Bench 全量测试集上达到 56.32\%；进一步参数优化后，四维查询配置达到 57.43\%，相较最强完整全库检索基线提升 7.02 个百分点，相较 MagicLens 直接检索提升 9.46 个百分点。与使用人工标注证据的参考设置 60.16\% 相比，本文框架仍存在进一步提升空间，但已经显著改善了非人工证据条件下的全库检索表现，说明查询侧规划、多路证据召回与列表融合能够有效缓解问题条件视觉证据召回困难。

{\small\noindent\textbf{关键词：}多模态检索增强生成；视觉证据召回；问题条件检索；多模态问答\par}

\begin{center}
{\zihao{3}\bfseries Abstract\par}
\end{center}
\addcontentsline{toc}{chapter}{Abstract}
\noindent\hspace*{\parindent}In vision-centric multimodal retrieval-augmented generation (mRAG), a system must retrieve external visual evidence according to both a query image and a question. The goal is therefore not only to find visually similar images, but to find evidence images that support question understanding and answer selection.

This thesis studies MRAG-Bench, where each task contains a query image, a question, and an external image corpus. To address this task, this thesis designs a three-stage retrieval-augmented architecture: query-side planning generates evidence-oriented retrieval expressions, visual evidence retrieval and fusion search the full corpus from multiple dimensions and merge the results, and a vision-language model produces the final multiple-choice answer from the query image, retrieved evidence, and question text.

Experiments show that full-corpus visual retrieval remains a key bottleneck. CLIP direct retrieval reaches 50.41\%, CLIP retrieval followed by MagicLens reranking reaches 50.33\%, and MagicLens direct retrieval reaches 47.97\%. The initial multidimensional fusion framework reaches 56.32\% on MRAG-Bench; after parameter tuning, the four-dimension configuration reaches 57.43\%, improving over the strongest full-corpus baseline by 7.02 percentage points and over MagicLens direct retrieval by 9.46 points. These results show that query-side planning, multi-route evidence retrieval, and list fusion can effectively improve full-corpus visual evidence retrieval without manually provided evidence.

{\small\noindent\textbf{Key words:} multimodal RAG; visual evidence retrieval; question-conditioned retrieval; multimodal question answering\par}
