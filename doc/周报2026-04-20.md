# 周报 2026-04-20

## 本周进展摘要

1. **多维 RAG 维度生成支持 Gemma 4 E2B-it（本地多模态）**  
   在 `test/pipeline_multi_dim_rag.py` 中增加 `--dim-generator-type gemma4_local`：用查询图 + MRAG-Bench 问题调用 Gemma4，生成 N 条英文 MagicLens 检索指令，再走各维 MagicLens、融合与 LLaVA。实现模块：`src/mrag/gemma4_loader.py`（与 `test/gemma4.py` 共用加载逻辑）、`src/mrag/gemma4_dims.py`。

2. **密钥与配置统一走 `.env`**  
   新增 `src/mrag/envfile.py`（轻量解析，无 python-dotenv 依赖）；`example.env` 列出 `DIM_GENERATOR_*`、`HF_TOKEN`、`GEMMA4_*` 等字段模板。`test/gemma4.py` 与 pipeline 入口在解析参数前加载仓库根目录 `.env`。

3. **文档**  
   架构说明、与 MagicLens 的关系、可复制命令见 **`doc/GEMMA4_MULTI_DIM_PIPELINE.md`**。

## 对导师可表述的要点

- **问题**：纯文本大模型做「多维检索 query」时看不到查询图，分解维度可能偏离图像内容。  
- **做法**：暂用已下载的 **Gemma 4 E2B-it 多模态模型**，把 **同一 query 图 + 问题** 输入模型，按系统提示输出 **N 条互补的英文检索指令**；每条指令与 query 图一起送入 **MagicLens** 做指令式图像检索，多路结果 **RRF 等策略融合** 后交给 **LLaVA** 作答。  
- **工程**：API / 本地文本 HF / **Gemma4 本地** 三种维度生成方式可通过 CLI 切换；密钥只放在 `.env`，仓库内仅保留 `example.env` 模板。

## 本地验证命令（从本文复制即可）

```bash
cd /path/to/mRAG
cp example.env .env   # 编辑 .env 填入 HF_TOKEN、按需填入 DIM_GENERATOR_API_KEY

python test/gemma4.py --mode run --device cuda:1

export CORPUS_DIR=/path/to/image_corpus
python test/pipeline_multi_dim_rag.py \
  --corpus-dir "${CORPUS_DIR}" \
  --dim-generator-type gemma4_local \
  --gemma4-device cuda:1 \
  --n-dims 3 \
  --max-samples 2 \
  --answers-file log/E8/gemma4_multi_dim_smoke.jsonl \
  --summary-out log/E8/gemma4_multi_dim_smoke_summary.json
```
